# Omni-Weave Bigram Reference Table

Standardised definitions for phonetic bigrams used in Omni-Weave runs. Each bigram carries fixed cross-language definitions regardless of which word it appears in. Context-sensitivity enters only at Layer 1 and above. No compressions -- each bigram stands on its own as a unit, not as the beginning of a longer word.

Entries marked ⚠ need cross-language review before being treated as settled.

---

## Rules

- Definitions are locked per bigram. The same bigram gets the same definitions in every weave run.
- If a longer word starts with these two letters, that is irrelevant unless the two-letter form is itself a genuine standalone root.
- Doubling (DD, NN etc) = intensification/total closure of the preceding unit. Not a language-specific meaning -- a structural one.
- When definitions across languages genuinely cluster, note the cluster. When they scatter, hold the scatter as ambiguity and note it explicitly.
